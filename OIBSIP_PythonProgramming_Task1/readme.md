# BMI Tracker Pro

A modern health analytics desktop application built using Python and CustomTkinter.

## 🚀 Features

- BMI Calculation
- BMI Categorization
- Height Unit Conversion (cm, m, ft/in)
- Body Fat Percentage Estimation
- Daily Calorie Requirement Calculation
- Ideal Weight Range Suggestion
- Weight Gain/Loss Recommendation
- Historical BMI Tracking
- Pie Chart Visualization
- SQLite Database Integration
- Modern Dark UI using CustomTkinter

## 📊 Technologies Used

- Python
- CustomTkinter
- SQLite
- Matplotlib

## 🖥️ How to Run

Install required libraries:

```bash
pip install customtkinter matplotlib
```
